# Presentations

Strategy decks and planning documents for Haka Egypt initiatives.

## Contents

- **`egypt-coffee-concepts.html`** — Interactive slide deck (14 slides) for three specialty coffee concepts designed for the 2026 Egyptian market. Open in any modern browser.
- **`egypt-coffee-concepts.md`** — Written companion with full narrative, menu details, economics, risks, and Midjourney / DALL·E image prompts for all three concepts.

## Viewing the deck

```bash
# From the repo root
open docs/presentations/egypt-coffee-concepts.html
# or serve the docs folder
npx serve docs
```

The HTML deck is self-contained and loads reveal.js from a CDN — no build step.
